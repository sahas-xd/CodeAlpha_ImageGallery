
# VisualVerse — Responsive Image Gallery

A modern, responsive photography gallery built for
the CodeAlpha Frontend Development Internship.

## Features
- Responsive image gallery
- Category-based image filtering
- Fullscreen-style lightbox
- Next and previous image navigation
- Keyboard navigation
- Smooth hover effects and transitions
- Mobile-friendly design

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)

## How to Run
1. Clone or download the repository.
2. Open the project folder.
3. Launch index.html in your browser.
4. An internet connection is required for sample images.

## Project Structure
- index.html — Website structure
- style.css — Styling and responsive layout
- script.js — Gallery functionality
